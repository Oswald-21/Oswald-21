# Hi, I'm Oswald! 👋

## About Me

I'm a web developer with around a year of experience, building frontend and backend applications and currently expanding my skills into mobile development.

I learn by building real projects, from social platforms to tools that help people organize their day. I care about clean interfaces, maintainable code, and understanding how people use what I build.

My approach is simple: turn ideas into useful, intuitive experiences. After all, we're all users at some point. ;)

---

## What I'm Working On

I'm currently working on a few projects that allow me to explore different aspects of software development.

### 🌐 Social Network
A social networking platform focused on connecting users through profiles, publications, interactions, and messaging.

**Technologies:** PHP, JavaScript, MariaDB, HTML & CSS.

### 📋 Task Manager
A task management application designed to organize everyday activities through a simple and intuitive interface.

**Technologies:** JavaScript, PHP, MySQL, HTML & CSS.

### 🛍️ Store App
An application focused on exploring and managing a digital shopping experience.

**Status:** In development.

These projects are helping me improve my skills in application architecture, database design, frontend development, and backend integration.
